# 🏥 Sistema Hospitalar - WinForms

Aplicação desktop criada em **VB.NET** utilizando **Windows Forms**, simulando todo o processo de atendimento hospitalar: recepção, triagem, consulta médica e histórico dos pacientes.

---

## 📌 Principais Recursos

- ✅ Tela de login com verificação de credenciais
- ✅ Registro de novos pacientes
- ✅ Triagem com definição de prioridade:
  - Normal
  - Urgente
  - Pouco urgente
- ✅ Atendimento médico com inserção de diagnóstico e finalização do processo
- ✅ Histórico detalhado de atendimentos, com opções de filtragem
- ✅ Interface intuitiva com navegação entre diferentes módulos

---

## 🛠️ Tecnologias

- **Visual Basic .NET**
- **Windows Forms**
- **SQLite**
- **Visual Studio**
